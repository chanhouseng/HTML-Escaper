# HTML 尖括號轉換器設計規格

## 目標

建立一個可直接以瀏覽器開啟的單一 `index.html` 工具。使用者輸入文字並按下「轉換內容」後，工具只把所有 `<` 轉成 `&lt;`，把所有 `>` 轉成 `&gt;`；其他字元（包括 `&`）保持不變。使用者可以按「複製結果」複製轉換後的文字。

## 技術與檔案結構

- 僅建立一個 `index.html`，內嵌 HTML、CSS 與原生 JavaScript。
- 不使用框架、套件、後端或網路請求。
- 所有內容只在瀏覽器本機處理。

## 介面設計

- 使用繁體中文與簡潔專業的藍灰色視覺風格。
- 頁首簡短說明工具用途，並標示內容不會被上傳。
- 桌面畫面左右並排「原始內容」與「轉換結果」文字區；窄螢幕改為上下排列。
- 主要操作為「轉換內容」，次要操作為「清除內容」及「複製結果」。
- 結果欄設為唯讀，避免使用者誤改。
- 所有按鈕具備清楚的鍵盤焦點、停用狀態與操作回饋。

## 行為與資料流程

1. 使用者在原始內容文字區輸入任意文字。
2. 按下「轉換內容」時，JavaScript 依序套用全域取代：`<` 變成 `&lt;`，`>` 變成 `&gt;`。
3. 轉換結果寫入唯讀結果欄。
4. 按下「複製結果」時，將結果的純文字內容寫入系統剪貼簿，並短暫顯示「已複製」。
5. 「清除內容」會清空輸入、結果與狀態訊息，並把焦點移回輸入欄。

## 邊界與錯誤處理

- 輸入為空或只有空白時，不執行轉換，顯示「請先輸入要轉換的內容」。
- 尚無結果時停用「複製結果」。
- 剪貼簿 API 不可用或被拒絕時，使用相容的瀏覽器備援複製方法；若仍失敗，提示使用者手動選取結果複製。
- 不轉換 `&`、引號或其他 HTML 特殊字元，這是刻意限定的功能範圍。

## 無障礙與響應式要求

- 每個文字區都有可見標籤，狀態訊息使用 `aria-live`。
- 支援鍵盤操作與 `:focus-visible` 樣式。
- 色彩對比足以閱讀，並尊重 `prefers-reduced-motion`。
- 手機寬度下按鈕與文字區保持可觸控且不產生水平捲動。

## 驗收標準

- `<div>Hello</div>` 轉換為 `&lt;div&gt;Hello&lt;/div&gt;`。
- `A & B` 保持為 `A & B`。
- 多個與相鄰的尖括號全部正確轉換。
- 空白輸入會顯示提示，不產生結果。
- 複製按鈕可複製與結果欄完全相同的文字，並顯示成功或失敗回饋。
- 版面在桌面及手機尺寸均清楚可用。
