# 尖括號轉換器

一個純前端的小工具，將文字中的 `<` 與 `>` 轉換為 HTML 實體字元，方便把 HTML 標籤以純文字形式顯示或貼到其他地方。

所有內容都只在你的瀏覽器中處理，不會上傳到任何伺服器。

## 功能

- 將所有 `<` 轉換為 `&lt;`
- 將所有 `>` 轉換為 `&gt;`
- 保留其他字元原樣，包括 `&`
- 一鍵複製轉換結果
- 可清除輸入與結果
- 支援 `Ctrl + Enter` 快速轉換
- 桌面版固定在單一視窗高度；長內容只會在文字框內捲動

## 使用方式

1. 在「原始內容」輸入或貼上文字。
2. 點擊「轉換內容」。
3. 在「轉換結果」取得已轉換的文字。
4. 點擊「複製結果」複製到剪貼簿。

例如：

```text
輸入：<div>Hello</div>
輸出：&lt;div&gt;Hello&lt;/div&gt;
```

```text
輸入：A & B
輸出：A & B
```

## 在本機執行

這是一個單檔網站，不需要安裝套件或啟動伺服器。

直接下載或複製專案後，以瀏覽器開啟 `index.html` 即可使用。

```text
html_escaper/
└── index.html
```

## 技術

- HTML5
- CSS3
- 原生 JavaScript
- Clipboard API，並提供舊版瀏覽器的複製備援

核心轉換邏輯：

```js
function escapeAngleBrackets(value) {
  return value.replaceAll('<', '&lt;').replaceAll('>', '&gt;');
}
```

## 開發對話摘要

這個工具由一段需求對話逐步定義：

> 我想寫一個網站是用戶給一段內容到輸入框，然後按 button 就將內文所有的 `<` 變成 `&lt;`，把所有的 `>` 變成 `&gt;`，用戶按 copy button 即可複製已更改的內文。

後續確認了以下決定：

- 採用單一 `index.html`，可直接開啟使用。
- 介面使用繁體中文與簡潔專業的工具風格。
- 轉換必須由按鈕觸發，不採即時轉換。
- 僅轉換 `<` 與 `>`，不轉換 `&`、引號或其他字元。
- 加入「清除內容」、複製成功提示，以及空白輸入提示。
- 桌面版不應讓頁面上下滑動，因此固定為單一視窗高度；過長內容改由文字框內部捲動。
